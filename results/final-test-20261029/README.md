## Состав архива

- `rules.jsonl`, `grobid.jsonl`, `ollama.jsonl` — исходные строки и результаты извлечения, статусы и время. Для GROBID и Qwen сохранён также исходный ответ сервиса в `rawResponse`; у правил это поле пустое, поскольку внешнего сервиса нет.
- `run.json`, `summary.json` — сведения о запуске, настройки, промпт, схема ответа, версии и digest модели.
- `protocol/` — зафиксированный протокол, критерии оценки и исполняемый `application.jar`, использованный для TEST. SHA-256 JAR указан в `protocol.json`.
- `evaluation/` — метрики, сравнения по каждой записи и полю, расхождения и контрольные суммы исходных данных.
- `formatting/` — результаты общего форматтера и контекст оформления.
- `quality/` — показатели и незаполненный бланк предметной проверки.
- `SHA256SUMS` — контрольные суммы всех остальных файлов этой папки.

Исходный датасет опубликован в корне репозитория: `датасет.xlsx`, SHA-256 `ef2204f408cb3b767466f48f863660fbc56ddb68702495f6b13fdbe34db368e2`.

## Ограничения

Извлечение в этом архиве рассчитано. `quality/` хранит первоначальный пустой бланк; [завершённая проверка](../review-20261029/README.md) опубликована отдельно. Старые pending/null отражают состояние до проверки. У Qwen 228 EXTRA — расхождения с пустым эталонным полем, а не 228 подтверждённых выдумок.

Абсолютные пути и адреса localhost в метаданных описывают среду исходного запуска. Для чтения архива эта среда не нужна. Для повторного расчёта метрик используйте сохранённый JAR и датасет с указанной контрольной суммой; пути задавайте для своей системы. Повторный запуск моделей не требуется.

Проверка контрольных сумм из этой папки на macOS:

```sh
shasum -a 256 -c SHA256SUMS
```
