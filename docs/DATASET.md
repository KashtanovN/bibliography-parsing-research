## Контракт

Читается лист «Датасет», заголовки первой строки уникальны, порядок колонок не важен. Лист «Источники» используется для происхождения и оснований, но не передаётся парсерам.

Основная таблица содержит 27 столбцов: ID, исходная ссылка, вариант оформления, 17 полей (авторы, заглавие, содержащее издание, год, том, номер/выпуск, страницы/объём, значение страниц, издатель, место, сведения об издании, ISBN, URL, дата обращения, DOI, EDN, вид документа), ГОСТ, тип исходного списка, DEV/TEST, группа, URL и дата контекста, неоднозначные поля.

ID уникальны и не перенумеровываются при чтении. Одна группа не может принадлежать одновременно DEV и TEST. Исходная строка сохраняется побуквенно, формулы и ошибки отклоняются. Даты: календарная дата Excel, `YYYY-MM-DD` или `DD.MM.YYYY`. Профили: `ГОСТ Р 7.0.5–2008` и `ГОСТ Р 7.0.108–2022`. Коды символов загрузчик не декодирует; в этой поставке используются сами символы.

## Извлечение и контекст

Метод получает только исходную строку через `ParserInput(id, rawCitation)`; сетевому сервису ID не передаётся. Эталон, группа, DEV/TEST и контекст в запрос не попадают.

«URL из исходной строки» и «Дата обращения из строки» — оцениваемые извлекаемые поля. «URL выбранной сетевой версии» и «Дата обращения для оформления» — фиксированный контекст, одинаковый для всех четырёх методов. Наличие DOI само по себе не выбирает профиль.

Колонка «Неоднозначные поля» в текущем файле пуста. Поддержка масок в загрузчике — возможность формата: непустые имена разделяются `;`, пустая ячейка или «нет» означает отсутствие исключений. Все 400 строк TEST участвуют в знаменателе полного совпадения и проверки оформления.

Человеческая проверка эталона и проверка выходных ссылок методов — разные процедуры. Для численного согласия нескольких разметчиков нужны их отдельные исходные разметки и явный знаменатель; программа такое согласие не придумывает. Разбиение не заявляется независимо сформированным слепым holdout. Подробнее: [показатели статьи](ARTICLE_METRICS.md).
