## Структура и контракт

Читается только лист «Датасет», первая строка — заголовки. Их порядок не важен, имена уникальны. Лист «Источники» служит для поиска оригиналов и не передаётся парсерам. Загрузчик не заменяет символы тире и не исправляет ячейки.

В основной таблице 27 колонок:

- ID, исходная ссылка, вариант оформления;
- 17 полей: авторы, заглавие, содержащее издание, год, том, номер или выпуск, страницы или объём, значение страниц, издатель, место издания, сведения об издании, ISBN, URL из исходной строки, дата обращения из строки, DOI из исходной строки, EDN, вид документа;
- применяемый ГОСТ, тип исходного списка, часть набора, группа разделения, URL выбранной сетевой версии, дата обращения для оформления, неоднозначные поля.

ID уникальны. Один ключ группы не может находиться в обеих частях. Не следует определять группу по URL цитируемой публикации: ключ уже задан в Excel. Отсутствующие реквизиты не заполняются. Формулы и ошибки в читаемых данных отклоняются.

Исходная ссылка должна быть текстом и сохраняется побуквенно. Даты читаются как календарные даты Excel, `YYYY-MM-DD` или `DD.MM.YYYY`. Профили: `ГОСТ Р 7.0.5–2008` и `ГОСТ Р 7.0.108–2022`.

## Вход, эталон и оформление

`ParserInput` содержит только `id` и `rawCitation`; внешнему парсеру передаётся только строка. Эталон, DEV/TEST, группа и контекст не включаются в промпт или запрос.

`URL из исходной строки` и `Дата обращения из строки` — извлекаемые поля. `URL выбранной сетевой версии` и `Дата обращения для оформления` — общий внешний контекст форматирования, одинаковый для четырёх методов. В частности, дата 27.10.2026 не является датой из исходной строки. Происхождение контекстной даты сохранено на листе «Источники». Наличие DOI не выбирает ГОСТ автоматически.
