# Загрузка исследовательского датасета

Актуальный файл — [`датасет.xlsx`](../датасет.xlsx).

## Запуск

Из каталога `backend`:

```sh
./mvnw package
java -jar target/bibliography-1.0.0.jar --check-dataset=../датасет.xlsx
```

Можно передать абсолютный путь к другому файлу с той же структурой. Путь с пробелами заключите в кавычки вместе со всем аргументом. При ошибке данных команда завершается с кодом 2. База данных и веб-сервер не запускаются; сетевых запросов при чтении файла нет. Первичная сборка Maven загружает зависимости.

У актуального файла ожидаются 500 записей: 92 dev, 408 test, 203 группы источников, 7 неоднозначных пар в 6 записях. JSON-сводка содержит также SHA-256 файла, число строк по источникам и профилям. Это проверка загрузки, а не результаты экспериментов с парсерами.

## Контракт Excel

- Читается только лист `Датасет`, заголовки — в первой строке. Порядок колонок не важен; имена должны быть уникальными.
- Обязательны ID, исходная ссылка, часть набора, группа разделения, тип исходного списка, 17 столбцов размеченных полей, профиль ГОСТ, URL выбранной сетевой версии, дата для оформления и вариант оформления. Пустые значения необязательных реквизитов допустимы.
- ID не повторяются; часть набора — `dev` или `test`; один ключ группы не может появляться в обеих частях. Ключ читается из файла, а не определяется по URL цитируемой статьи.
- Исходная ссылка должна быть текстом. Она сохраняется с пробелами, переносами и опечатками. Поля эталона читаются отдельно; отсутствующие значения не заполняются.
- Даты принимаются как календарные Excel-даты, `YYYY-MM-DD` или `DD.MM.YYYY`. Некорректные даты отклоняются.
- Читаются профили `ГОСТ Р 7.0.5–2008` и `ГОСТ Р 7.0.108–2022`. Это не означает, что сервис уже умеет форматировать оба профиля.
- Формулы и ошибки в ячейках основного листа отклоняются, а не исполняются. Листы `Контроль100`, `Исключения`, `Методика` не добавляют наблюдений и не передаются методам разбора.

## Разделение входа и эталона

`ResearchDataset.ParserInput` содержит ровно два поля: `id` и `rawCitation`. Через `dataset.parserInputs(Split.DEV)` или `dataset.parserInputs(Split.TEST)` будущий метод получает только эти данные.

`AnnotatedReference` предназначен для загрузчика и будущего оценщика: содержит эталонные поля, флаги неоднозначности, часть набора, группу источника и контекст оформления. Его нельзя передавать в промпт LLM или использовать как вход правил/GROBID. `FormattingContext` — отдельный вход стадии оформления.

`URL из исходной строки` и исходная дата обращения относятся к извлечению; `URL выбранной сетевой версии` и `Дата обращения для оформления` — к отдельному контексту. Эти значения не подменяют друг друга.

## Неоднозначности

В текущем Excel флаги читаются из фразы `Неоднозначные поля: ... .` в примечаниях; названия разделяются точкой с запятой. Если есть отдельный столбец `Неоднозначные поля`, используется он. `нет` и пустая ячейка означают отсутствие флагов; неизвестное имя вызывает ошибку загрузки.

Кандидатное значение и его неоднозначность сохраняются отдельно. Пустое значение само по себе не означает неоднозначности. В текущем наборе отмечены: R429 — номер, R375 — роль страниц, R103 — вид документа, R514 — содержащее издание и вид, R409 — издатель, R437 — авторы. Будущий оценщик должен отдельно учитывать эти флаги; расчёт метрик пока не реализован.

## Проверка

```sh
./mvnw -Dtest=ExcelDatasetLoaderTest test
```

Тесты проверяют актуальный файл, отделение входа от эталона, сохранение сырого текста, различение дат, дубликаты ID и заголовков, пересечение групп dev/test, неверные даты, неизвестные профили, формулы, пустые строки и неоднозначности.
