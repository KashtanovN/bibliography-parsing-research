# Показатели статьи и файлы эксперимента

Текущая версия: 490 записей, DEV 90, TEST 400, 17 полей, четыре метода. Одна команда `bash scripts/run-experiment.sh` выполняет автоматические этапы с неизменными настройками. Сводка формируется после TEST.

Полный новый прогон 31.10.2026 завершён. Используйте [опубликованную сводку TEST](../results/2026-10-31/test-four-methods/article/report.md) и [отчёт Word](../results/2026-10-31/Замеры+ГОСТ+AnyStyle.docx). Все 1600 ответов TEST имеют статус SUCCESS. Micro F1: rules 0.957692, grobid 0.385710, ollama 0.892020, anystyle 0.478722. Числа полностью правильных записей: 296, 0, 74, 2 из 400. Автоматические таблицы готовы; 1600 решений по оформлению и 3885 решений по полям Qwen ещё не заполнены. Показатели проверки из предыдущих прогонов не переносятся на новые ответы.

Для TEST получаются 1600 ответов и 27200 сравнений «поле — запись — метод». Полное совпадение имеет знаменатель 400, масок нет. Для оформления все четыре метода проверяются на этих же 400 записях; сервисные ошибки входят как некорректный результат.

Счётчик `FORMATTED`, точное строковое совпадение с эталоном и отсутствие лишнего поля не заменяют предметные решения. Пока они не заполнены, итоги проверки не определены, не нулевые. Ошибочные и пустые вызовы не исключаются из F1.

Графики можно построить из сохранённых CSV без повторного вызова моделей. Статистическая значимость и межэкспертное согласие не появляются из этих таблиц автоматически. Длительности имеют разрешение миллисекунд; для быстрых правил учитывать долю нулевых значений.

Составление статьи выполняется по данным именно этого опыта. Наблюдения по фиксированному разбиению не объявляются новым независимым слепым holdout или доказательством качества на любых библиографических списках.
