# Перенос backend на Java — 27.10.2026

По запросу пользователя сервер заменён на Java 17 + Spring Boot 3.5.16. Перенос проверен локально 27.10.2026. По отдельному указанию пользователя 28.10.2026 Java-версия подготовлена для публикации в новом репозитории `KashtanovN/bibliography-parsing-research`, отдельно от сохранённой прежней версии.

## Состав

- React 19 + TypeScript + Vite: существующий интерфейс сохранён.
- Spring MVC: четыре REST-метода `/api/health/`, `/api/schema/`, `/api/format/`, `/api/import/`.
- Spring Data JPA/Hibernate: чтение и обновление схемы правил в PostgreSQL JSONB.
- Flyway: версионированные SQL-миграции.
- JDK HttpClient: Crossref/Open Library, тайм-ауты, ограничение ответа, без переходов по редиректам.
- Caffeine: кеш метаданных и локальные счётчики запросов.
- Maven Wrapper, JUnit 5, Spring Boot Test: сборка и проверки.
- Docker Compose + Nginx: конфигурация размещения.

Прежние серверные исходники, зависимости, команды запуска и настройки удалены из приложения. Отдельная прежняя среда выполнения не нужна. Интерфейс, исследовательский текст README, Excel и исходный JSON преподавателя сохранены.

## API и правила

Адреса, названия полей, форматы успешных ответов и используемые интерфейсом ошибки сохранены. Даты во входе `YYYY-MM-DD`, в ссылке `DD.MM.YYYY`. JSON правил перенесён без изменения байтов в `backend/src/main/resources/gost705.json`. Оригинал в `docs/source/` не менялся.

Нормализация ФИО повторяет распространённые варианты инициалов и разделителей. Это не универсальное распознавание имён; полные англоязычные имена из Open Library сохраняются. Crossref предоставляет family/given отдельно. Неизвестные поля, неверные ISBN, DOI, даты и значения обязательных полей отклоняются. Пустые необязательные блоки не выводятся вместе с разделителями.

Правила загружаются в существующую таблицу `bibliography_citationstandard`. При первом запуске стартовый профиль добавляется только при отсутствии записи. Для принятия существующей БД под Flyway предусмотрен однократный baseline уровня 0, см. [развёртывание](DEPLOYMENT.md). Правила можно заменить локальной CLI-командой, без административного HTTP-метода.

## Соответствие функциональным требованиям

| Требование | Текущее состояние |
|---|---|
| Ручная форма | 8 типов, включая диссертацию и автореферат |
| ГОСТ Р 7.0.5–2008 | Рабочий профиль; экспертиза библиотеки не зарегистрирована |
| DOI / ISBN | Crossref / Open Library, неполные сведения отмечаются |
| eLIBRARY / EDN | Явный HTTP 501, адаптер не реализован |
| Копирование и embedded-режим | Сохранены в React |
| История / личный кабинет / LDAP | Не реализованы |
| Пакетный разбор произвольных ссылок | Не реализован |
| Дополнительные стили / профиль 108–2022 | Не реализованы в сервисе |

Смена стека не подтверждает выполнение всего расширенного ТЗ. Исследовательские профили в Excel и рабочий профиль сервиса имеют разное назначение. Указанный в исходном ТЗ стек следует обновить после согласования.
