# Проверки текущей версии

29 октября 2026 года. Исследовательские результаты опубликованы в [results](../results/README.md). Тесты приложения проверяют реализацию, а не заменяют измерение качества методов.

## Автоматические проверки

- Backend: `cd backend && ./mvnw verify` — 163 теста без ошибок и пропусков; сборка исполняемого JAR. Тестовая БД PostgreSQL отделена от рабочей.
- Frontend: `cd frontend && npm run build` — проверка TypeScript и production-сборка.
- Проверяются четыре адаптера, отсутствие эталона в запросах, ошибки и тайм-ауты, общий форматтер, полевые TP/FP/FN, маски неоднозначности, решения проверки качества, фиксация DEV/TEST и отклонение изменённых артефактов.
- Общий `all` включает rules, GROBID, Qwen и AnyStyle; полный протокол сохраняет конфигурации всех четырёх. Архивные протоколы продолжают воспроизводиться собственными JAR.
- Скрипты запуска/мониторинга проходят проверку Bash и проверку сценариев без обращения к моделям.

## Целостность и ограничения

Датасет SHA-256: `ef2204f408cb3b767466f48f863660fbc56ddb68702495f6b13fdbe34db368e2`. Все публикуемые архивы содержат SHA256SUMS. Проверены состав 408 ID каждого метода, совпадение исходных строк, контексты оформления, построчные TP/FP/FN и связь с версиями протоколов. При актуализации документации парсеры не запускались; исходные ответы и метрики извлечения не менялись.

В журнале проверки отмечены 27 фактических ответов Qwen с возможной ошибкой/неполнотой эталона; три выводимые категории остаются неоднозначными. Исправление эталона требует новой версии и повторного расчёта всех методов. Исследовательская проверка не является аттестацией всех шаблонов ручной веб-формы, специальных вариантов стандартов или дополнительной функциональности сервиса.

История прошлых проверок доступна в Git. Неактуальные промежуточные суммы тестов и результаты диагностического DEV не используются как текущие показатели.
