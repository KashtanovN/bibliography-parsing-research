# Проверки текущей версии

Проверки программы и среды не являются результатами качества методов.

Перед новым полным прогоном 31.10.2026 повторно выполнены Maven verify (165 тестов, без ошибок и пропусков), пять Python-проверок сценария/сводки и проверка синтаксиса всех shell-сценариев. Семь исправленных выпусков проверены через фактический загрузчик Java; после тестов Excel побайтно совпадает с предоставленным автором файлом. Метаданные сервисов: [preflight.json](../results/preflight.json), статус READY_FOR_DEV. Проверка frontend из предыдущего этапа остаётся применимой: код интерфейса не изменён.

```sh
cd backend
./mvnw verify
cd ../frontend
npm run build
cd ..
python3 -m unittest discover -s backend/src/test/python -v
bash scripts/check-research-environment.sh
```

Проверяются загрузка Excel без изменения байтов, все четыре адаптера, отсутствие передачи эталона, обработка HTTP/JSON и тайм-аутов, форматтер, TP/FP/FN, поддержка масок, протокол, контрольные суммы и сценарии запуска. Программные тесты используют отдельные фикстуры и тестовую PostgreSQL, не производственную базу.

Данные: 490 записей, DEV 90, TEST 400, 203 группы. Масок неоднозначности нет. SHA-256 `0b2f9cb80ef53994e608f61677f7bc1b9d807b7bfcdcd08a97202d8d6f7a168d`. Исходный предоставленный файл и репозиторная копия должны совпадать побайтно. Эксперимент проверяет [Dataset.sha256](../Dataset.sha256) перед этапами.

Проверка среды получает только метаданные GROBID/Ollama/AnyStyle и сообщает `inferencePerformed=false`. Успех означает готовность на момент проверки; реальные версии, параметры и исходные ответы сохраняются в прогоне.

`run-experiment.sh` проверяется без моделей на фикстурах: порядок DEV → фиксация → TEST → сводка, остановка при ошибке, отказ перезаписи и неизменность Excel. Подробности сборки — `backend/target/surefire-reports/`.

Автоматические показатели находятся в `evaluation/` и `article/`. Доли корректного оформления и подтверждённых добавлений публикуются после заполнения бланка, согласно [протоколу](QUALITY_REVIEW.md). Результат автоматической загрузки не является независимой проверкой разметки или нормативной экспертизой.

Проверено 31.10.2026: Maven verify — 165 тестов без ошибок и пропусков; пять проверок сценария и сводки на Python — успешно; frontend TypeScript/Vite — успешно.
