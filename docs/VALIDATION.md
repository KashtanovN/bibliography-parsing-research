## Проверки сборки

```sh
cd backend
./mvnw verify
cd ../frontend
npm run build
```

Backend проверяет загрузку актуального Excel без изменения, все четыре адаптера, отделение эталона от входа, HTTP/JSON и тайм-ауты, форматтер, TP/FP/FN, маски, фиксацию протокола, отклонение изменённых файлов, скрипты запуска и мониторинга. Тестовая PostgreSQL отделена от рабочей. Результат конкретной сборки находится в `backend/target/surefire-reports/`.

31.10.2026: `./mvnw verify` — 164 теста без ошибок и пропусков, исполняемый JAR собран; `npm run build` — успешная TypeScript/Vite-сборка. Bash-синтаксис шести скриптов проверен. Сценарий DEV проверен без моделей: все четыре метода, без лимита и автоматической фиксации, с отклонением повторного запуска в ту же папку.
