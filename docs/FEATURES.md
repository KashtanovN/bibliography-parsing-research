# Возможности сервиса

Русскоязычный сервис оформления библиографических ссылок: Java 17 + Spring Boot 3.5.16, React 19 + TypeScript + Vite и PostgreSQL.

## Состав приложения

- Spring MVC: четыре REST-метода `/api/health/`, `/api/schema/`, `/api/format/`, `/api/import/`.
- Spring Data JPA/Hibernate: чтение и обновление схемы правил в PostgreSQL JSONB.
- Flyway: управление структурой базы данных с помощью версионированных SQL-файлов.
- JDK HttpClient: запросы к Crossref/Open Library с тайм-аутами и ограничением ответа, без переходов по редиректам.
- Caffeine: кеш метаданных и локальные счётчики запросов.
- Maven Wrapper, JUnit 5, Spring Boot Test: сборка и проверки.
- Docker Compose + Nginx: развёртывание приложения.

## API и правила

Даты передаются в API в формате `YYYY-MM-DD`, в ссылке выводятся как `DD.MM.YYYY`. Рабочий JSON правил находится в `backend/src/main/resources/gost705.json`, справочный исходный JSON — в `docs/source/`.

Нормализация ФИО обрабатывает распространённые варианты инициалов и разделителей. Это не универсальное распознавание имён; полные англоязычные имена из Open Library сохраняются. Crossref предоставляет фамилию и имя отдельно. Неизвестные поля, неверные ISBN, DOI, даты и значения обязательных полей отклоняются. Пустые необязательные блоки не выводятся вместе с разделителями.

Правила хранятся в таблице `bibliography_citationstandard`. При первом запуске стартовый профиль добавляется только при отсутствии записи. Правила можно обновить локальной CLI-командой; описание — в [инструкции развёртывания](DEPLOYMENT.md#обновление-правил).

## Функциональность

| Возможность | Текущее состояние |
|---|---|
| Ручная форма | 8 типов, включая диссертацию и автореферат |
| ГОСТ Р 7.0.5–2008 | Рабочий профиль; требуется предметная проверка библиотекой |
| DOI / ISBN | Crossref / Open Library, неполные сведения отмечаются |
| eLIBRARY / EDN | HTTP 501 с пояснением; адаптер не реализован |
| Копирование | Готовую ссылку можно скопировать в буфер обмена |
| Режим встраивания | Параметр `?embedded=1` скрывает университетскую шапку и подвал |
| История / личный кабинет / LDAP | Не реализованы |
| Пакетный разбор произвольных ссылок | Не реализован |
| Дополнительные стили / профиль 108–2022 | Не реализованы в сервисе |

Исследовательские профили в Excel и рабочий профиль сервиса имеют разное назначение. Возможности приложения не охватывают всё расширенное ТЗ.
