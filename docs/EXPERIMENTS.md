# Запуск и сохранение эксперимента

Четыре метода: `rules`, `grobid`, `ollama`, `anystyle`. Датасет содержит 490 записей: 90 DEV и 400 TEST. SHA-256 фиксируется файлом [Dataset.sha256](../Dataset.sha256): `b18b1e2d3d7ab35744874a095fd50fad4cbeecfdd497ef6d1a7fcbc020ccc657`.

## Один автоматический процесс

После установки сервисов и `cd backend && ./mvnw verify` из корня проекта:

```sh
bash scripts/run-experiment.sh
```

Последовательность:

1. Проверка неизменности Excel и наличия JAR; проверка метаданных сервисов без извлечения.
2. Полный DEV четырёх методов: 360 ответов, оценка 17 полей и оформление.
3. Фиксация протокола и JAR при тех же настройках. Автоматической настройки по ответам DEV нет; это запуск зафиксированного сравнения.
4. Полный TEST четырёх методов: 1600 ответов, оценка, оформление и бланк проверки качества.
5. Сводка автоматических показателей и длительностей для статьи.

Папки `research-runs/dev-four-methods` и `research-runs/test-four-methods` должны отсутствовать. Запуск не перезаписывает результаты, не исправляет датасет и не повторяет неудачные вызовы автоматически. Код 3 извлечения означает завершённый проход с сохранёнными ошибками методов: такие ошибки входят в метрики. Другие ошибки останавливают процесс.

Состояние всего процесса: `research-runs/experiment.pipeline-status`, PID: `research-runs/experiment.pipeline.pid`. Итоговое состояние `AUTOMATIC_COMPLETED_REVIEW_REQUIRED` означает, что автоматические этапы закончены, а предметные решения ещё нужны. Это не заявление о нормативной корректности всех ссылок.

## Монитор

```sh
bash scripts/watch-test-progress.sh
```

Монитор автоматически выбирает DEV или TEST, читает число записей и методы из `run.json`. В терминале обновляет один экран каждые две секунды; без TTY выводит один снимок. `--once` также задаёт один снимок. Ctrl+C закрывает монитор, не измерения. Ориентир остатка Qwen появляется после трёх ответов и не включает остальные этапы. На macOS `caffeinate` удерживает машину от сна; оставьте крышку открытой.

## Отдельные этапы

Если требуется сначала самостоятельно изучить DEV и завершить настройку, вместо общего процесса запустите:

```sh
bash scripts/run-dev.sh
cd backend
java -jar target/bibliography-1.0.0.jar \
  --freeze-experiment=../research-runs/dev-four-methods --dataset=../Dataset.xlsx
cd ..
bash scripts/run-final-test.sh
python3 scripts/summarize-run.py research-runs/test-four-methods
```

Фиксация требует полного завершённого DEV без `--limit` и доступных метаданных всех четырёх методов. `frozen-protocol/` содержит `protocol.json`, SHA протокола, критерии оценки и `application.jar`. Сохраняются SHA данных, 90 DEV / 400 TEST, версии методов, модель/digest Qwen, конфигурация AnyStyle, промпт, нормализация, форматтер, тайм-аут и снимок реализации.

TEST работает сохранённым JAR, не допускает лимит и проверяет совпадение данных и настроек. Изменение файлов после фиксации отклоняется. Менять методы по увиденным ответам TEST нельзя в пределах данного опыта.

## Результаты

- `run.json`, `summary.json` и четыре JSONL: исходные строки, ответы, ошибки, длительности и метаданные.
- `evaluation/`: сводка precision/recall, micro/macro F1, F1 по 17 полям, полное совпадение, лишние/конфликтующие поля, журнал всех сравнений и контрольные суммы.
- `formatting/`: готовые ссылки и общий контекст; статус `FORMATTED` не является экспертным решением.
- `quality/`: бланк проверки оформления и всех непустых полей LLM. До проверки нормативные доли и подтверждённые добавления не определены.
- `article/`: автоматические таблицы и длительности, ссылки на файлы для предметной проверки. Перегенерация ответов для подготовки сводки не требуется.

Числовые показатели DEV диагностические; итоговые сравнительные таблицы относятся к TEST. Согласие разметчиков рассчитывается отдельно по независимым разметкам. [Карта показателей статьи](ARTICLE_METRICS.md), [проверка качества](QUALITY_REVIEW.md).

## Границы

Разбиение не заявляется независимо сформированным слепым holdout: корпус использовался при развитии методов. Применяются общие `field-evaluation-v2` и `shared-short-v1`. Нормализация не склеивает внутрисловные дефисы и переносы и не приравнивает раздел книги к материалу сборника. Эти правила одинаковы для всех методов. Внешние сведения не дополняют извлечение; полнота выбранного краткого профиля не равна экспертизе всех вариантов ГОСТ.
